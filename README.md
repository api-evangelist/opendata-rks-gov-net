# opendata.rks-gov.net (opendata-rks-gov-net) — OFFLINE

opendata.rks-gov.net (RKS Open Data) was the Republic of Kosovo's national government open-data portal, historically running **CKAN (~v2.7)**. As of mid-2025 the hostname no longer resolves (NXDOMAIN) and the portal is **offline**; cataloged here as historical pending restoration.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/opendata-rks-gov-net/refs/heads/main/apis.yml)

## Type
- **kind:** government  ·  **software:** CKAN (~2.7, historical)  ·  **status:** offline

## API
- **RKS Open Data CKAN Action API (historical)** — base `https://opendata.rks-gov.net/api/3/action` (host offline).
- Last Internet Archive snapshots: June 2025. Platform confirmed CKAN ~2.7 from archived pages.
- **Note:** `opendata.rks-gov.net` and `data.rks-gov.net` both return NXDOMAIN, while parent `rks-gov.net` and other government subdomains resolve normally. Sectoral services remain live: Kosovo Customs (`dogana.rks-gov.net/OpenData`) and the national geoportal (`geoportal.rks-gov.net`). Do not confuse with the NGO Open Data Kosovo (opendatakosovo.org).
